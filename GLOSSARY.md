# Glossary — Nivå Liften

Shared language for this project. Maintained by `/grill-with-docs` and `domain-modeling`. Dutch term first, as it appears on the site.

| Term | Meaning | Use on site / in code |
|---|---|---|
| **Nivå Liften** | The client. Always with å in copy | `niva` in code and URLs |
| **Liftonderhoud** | Periodic maintenance contract on a lift | Service; SEO keyword; `/diensten/liftonderhoud` |
| **Reparatie / storing** | Repair after a fault. A *storing* is a breakdown | Service; "Storing melden 24/7" is the urgent CTA |
| **Liftmodernisering** | Renewing parts (besturing, machine, deuren, tableaus) of an existing lift instead of replacing the whole lift. Nivå does 60–70 per year | Focus service; `/diensten/liftmodernisering` |
| **Modernisering compleet** | Full modernisation of all main components | Project scope label |
| **Nieuwbouw** | New lift installation | Service, listed last (focus moved away from it) |
| **Opsluiting** | Someone stuck in a lift | Used in 24/7 and IoT context |
| **VvE** (Vereniging van Eigenaars) | Homeowners' association of an apartment building; key customer segment | Audience; the old domain liftonderhoudvoorvve.nl targets them |
| **Commercieel** | Business / institutional clients (corporaties, property managers, hotels) | Audience segment |
| **Corporatie / Corporatielift** | Housing corporation / the lift type Nivå installs for them (type *Mars*: ≤2.500 kg, ≤1,60 m/s, ≤45 m) | Nieuwbouw page |
| **Merkonafhankelijk / alle fabricaten** | Nivå services every brand (Otis, Kone, Thyssen, Schindler, Mitsubishi) | Core USP |
| **Marktvrij** | Non-proprietary components any service company can maintain, so the client isn't locked to one brand | USP, Modernisering page |
| **Ontzorging** | Nivå takes the worry off the client: short lines, fair prices, portal | Voice word; use with facts |
| **Klantenportaal** | 24/7 online portal for clients | Link if client confirms |
| **MJOB** (Meerjarenonderhoudsbegroting) | Multi-year maintenance budget/plan | IoT/onderhoud context |
| **SafetyBlueBox / IoT-module** | Cloud-connected cabin module measuring vibration, position, ride behaviour; 5 installations so far | "Vooruitblik", don't overclaim |
| **Monteur** | Lift technician; Nivå has its own | Vacatures audience |
| **Besturing / regelaar / machine** | Controller / drive / motor | Modernisering page |
| **Drukknoptableau** | Push-button panel | Modernisering page |
